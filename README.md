### Основные (бизнес) задачи
1. Сформировать архитектуру приложения.
- - (Bus) Добавить класс Автобус.
	
2. (SorterDataBusCommand) Класс - команда, из которого будет запускаться приложение.
- - использовать паттерн внедрения зависимостей для класса и создать интерфейсы, которые будут внедряться:
- - - (IBusStorage) метод получения данных.
- - - (IBusValidator) Валидация.
- - - (IBusSorterFactory) фабрика сортировок.
- - - (IBusView) вывод класса автобус.
- - Реализовать алгоритм (метод execute()).
- - - сканнер определяющий как будем брать данные.
- - - Получение данных.
- - - Валидация.
- - - Сортировка.
- - - Вывод полученных данных.
		
3. (IBusStorage) Интерфейс: метод формирующий массив данных и его длину (объект реализующий этот интерфейс должен внедряться в SorterDataCommand).
- - класс, получающий данные из файла.
- - класс, данные которые формируются рандомно.
- - класс, которые вводятся вручную (через класс Scanner?).
	
4. BusDataValidator Класс, который валидирует данные.

5. BusBuilder. Реализовать класс, используя паттерн билдер.

6. Классы, которые сортируют данные по 3-м полям класса.
- - BusNumberSorter (сортирующий по номеру).
- - BusModelSorter (сортировка по модели).
- - BusMileageSorter (сортировка по пробегу).

К каждому классу добавить тесты.

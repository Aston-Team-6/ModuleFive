# Проект № 5

> Домашнее задание от команды № 6. Это **консольное приложение**, сортирующие объекты класса **автобус** по заданному критерию.
Проект предназначен для организаци Aston.

## Требования

1. Java `25`.
2. Система сборки: `Maven 3.8+`

## Установка

```bash
git clone https://github.com/Aston-Team-6/ModuleFive module-five
cd module-five
mvn clean isntall
```

## Тестирование

```bash
mvn test
```
